# Fila Virtual - Salão Express

> Um sistema de fila virtual desenvolvido para o Salão de Beleza Express, com o objetivo de modernizar o atendimento, melhorar a experiência das clientes e otimizar a rotina da equipe.

Este projeto permite que as clientes entrem na fila de atendimento remotamente através de um site, acompanhem sua posição em tempo real e sejam notificadas com antecedência.

## ✨ Funcionalidades

### Para Clientes

- Entrar na fila de atendimento remotamente através do site do salão.
- Visualizar a posição atual na fila e o tempo estimado para o atendimento.
- Receber notificações automáticas via WhatsApp e Push 30 minutos antes do horário previsto.
- Opção para cancelar o atendimento, se necessário.

### Para o Salão

- Painel de controle exclusivo para a equipe gerenciar a fila em tempo real.
- Adicionar clientes à fila manualmente (para clientes que chegam presencialmente).
- Finalizar atendimentos e avançar a ordem da fila.
- Acesso às informações de cada cliente, como nome e status da notificação.
- Visualização do histórico de atendimentos encerrados no dia.
